# AAGA-Ordonnancement-enumeration-triangle

Projet de AAGA fait par Elise LOUIS, Mickael VILAYVANH et Ryad AITTOUARES.

Pré-requis:

Python 3.12
Matplotlib

## Installation:
### Sur Windows et MacOS:
Lien vers les versions de Python: https://www.python.org/downloads/

### Sur Linux:
```
sudo apt update
sudo apt install python3 python3-pip -y
```

Pour MatplotLib, il faut utiliser la commande pip, peu importe l'OS
```
pip install matplotlib
```

Récupérer le projet en le clonant sur votre machine, ou télécharger le en ZIP.

## Exécuter

Afin d'exécuter le programme, depuis le répertoire racine du projet, tapez:

```
python3 main.py
```

Ce programme est libre de droit et libre d'édition.
